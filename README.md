# The hobby house es una página con productos de Franquicias.



Su propósito es funcionar como una página para la venta de productos de gran variedad como Bandai o Pokémon company, de momento solo e implementado 5 productos, en una sección de figuras.


en el nav he agregado de momento un único enlace, pero solo como una idea para que se entienda el propósito de su uso, en ese mismo enlace
llevaría a un archivo externo HTML, donde el usuario podría (si es posible en un futuro update) filtrar los tipos de productos de las franquicias, como Figuras, Pelcuhes o cartas y etc.


en la página se muestra un formulario con Formspree para que el usuario pueda dejar un mensaje a la página y una calificación de 1-5.

también se ha añadido fuentes locales de 3 de Google fonts


- Futuros agregados:

	- la funcionalidad de los enlaces con animaciones

	- Filtro para productos (si llega a ser posible)

	- mejorar el media-queries
